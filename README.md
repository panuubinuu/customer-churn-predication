A complete end-to-end **Machine Learning project** that predicts whether a Telco customer will churn (leave the service), using the IBM Telco Customer Churn Dataset (7,043 records) and an interactive **Streamlit dashboard** with 4 tabs.

---

## 🚀 Live Demo

Run locally at: **http://localhost:8501**

---

## 📌 Project Features

| Feature | Description |
|---------|-------------|
| **ML Model** | LightGBM Gradient Boosting Classifier |
| **Dataset** | IBM Telco Customer Churn (7,043 records) |
| **Accuracy** | ROC-AUC Score: **0.8406 (84.06%)** |
| **Dashboard** | Streamlit 4-tab interactive web app |
| **Visualization** | Plotly interactive charts & gauge meters |
| **XAI** | Feature Importance (Explainable AI) |

---

## 🖥️ Dashboard Tabs

### Tab 1: Single Customer Risk Prediction
- Fill a form with 15 customer attributes
- Get real-time churn probability (0–100%)
- Plotly Gauge Meter with color-coded risk (Green / Yellow / Red)
- Actionable retention recommendations for high-risk customers

### Tab 2: Batch CSV Scoring
- Download CSV template
- Upload CSV with multiple customers
- Get churn probability + status for each customer
- Download scored results as CSV

### Tab 3: Feature Importance (XAI)
- Horizontal bar chart of LightGBM split-based feature importance
- Understand which features drive churn predictions

### Tab 4: Dataset Analytics (EDA)
- KPI metrics: Total Customers, Churn Rate, Avg Tenure, Avg Bill
- Churn by Contract Type (grouped bar chart)
- Tenure distribution by Churn Status (box plot)

## ⚙️ Installation & Setup

### Step 1: Clone the repository
```bash
git clone https://github.com/panuubinuu/churn-predictor.git
cd churn-predictor
```

### Step 2: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 3: Train the model (downloads dataset automatically)
```bash
python train.py
```
This will generate:
- `churn_artifacts.pkl` — Trained LightGBM model
- `telco_clean.csv` — Cleaned dataset

### Step 4: Launch the dashboard
```bash
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

## 📊 Model Details

| Parameter | Value |
|-----------|-------|
| Algorithm | LightGBM Classifier |
| n_estimators | 150 |
| learning_rate | 0.05 |
| max_depth | 5 |
| Train/Test Split | 80% / 20% (Stratified) |
| ROC-AUC Score | **0.8406** |

---

## 🔍 Key Insights

- **Contract Type** is the strongest churn predictor — Month-to-month customers churn most
- **Tenure** matters — customers with < 12 months tenure are highest risk
- **Monthly Charges** — higher bills correlate with more churn
- **Payment Method** — Electronic check users churn more than automatic payment users
